# Memória do Claude - Daniella

Repositório para guardar o perfil e contexto de Daniella. Este arquivo é preenchido progressivamente com informações sobre preferências, experiências, conhecimentos e feedback.

## Como usar

1. Clone este repositório localmente
2. Edite `memory.md` para adicionar/atualizar informações sobre você
3. Faça commit e push das mudanças
4. Ao usar Claude Code, aponte para o arquivo `memory.md` para ter seu contexto pessoal carregado

## Estrutura do memory.md

O arquivo segue o padrão de memória do Claude com as seções:
- **user**: Informações sobre você, seu papel, conhecimentos
- **feedback**: Como você prefere que Claude trabalhe com você
- **project**: Contexto de projetos em andamento
- **reference**: Links e referências úteis

## Começar

Abra `memory.md` e comece a preencher seu perfil!
